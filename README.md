# TRUNG TÂM NGOẠI NGỮ WEBSITE
**TRUNG TÂM NGOẠI NGỮ WEBSITE** giúp học viên *tìm hiểu, đăng kí* các chương trình học ngoại ngữ phù hợp cho cá nhân.
## 1.Bảng dự án
|Thư mục|Nội dung|
|:-|:-|
|`data`|Dữ liệu đăng kí của khách hàng|
|`docs`|Thời khoá biểu|
|`medie'|Logo trung tâm hoặc các tài nguyên khác|
## 2.Lệnh Powershell liệt kê
```powershell
Get-ChildItem -Force
```
## 3.Công việc cần làm 
- [x] Tạo cấu trúc thư mục dự án trung tâm
- [ ] Hoàn thiện dữ liệu đăng kí của khách hàng

‼️NOTE
> ### Tuyệt đối không upload file .env lên Git hoặc các nền tảng public để tránh lộ dữ liệu.
